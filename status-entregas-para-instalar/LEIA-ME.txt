STATUS DE ENTREGAS — COPACOL

O QUE PRECISA TER NO COMPUTADOR
- Node.js instalado (versao 18 ou mais recente).
- O computador e o celular conectados a mesma rede local.

COMO INICIAR NO WINDOWS
1. Extraia o arquivo ZIP para uma pasta, por exemplo C:\StatusEntregas.
2. Instale o Node.js, se ainda nao estiver instalado.
3. Abra a pasta extraida e clique duas vezes em iniciar-status.bat.
4. A pagina abre no navegador do computador. Mantenha a janela preta aberta.
5. Para o celular, descubra o IPv4 do computador com o comando ipconfig.
   No celular conectado a mesma rede, acesse:
   http://IP-DO-COMPUTADOR:8080/status.html
   Exemplo: http://192.168.1.25:8080/status.html

IMPORTANTE
- Mantenha a janela preta aberta enquanto usa a pagina; fecha-la para o servidor.
- Se o Firewall do Windows perguntar, permita o Node.js em redes privadas.
- Se a porta 8080 ja estiver ocupada, abra o PowerShell e rode:
  $env:PORT=8081; npm start
  Nesse caso, substitua 8080 por 8081 no endereco do navegador.
- Os registros compartilhados ficam em data\trips.json. Faca uma copia de
  seguranca desse arquivo periodicamente.
- O computador precisa estar ligado e o servidor em execucao para sincronizar
  as alteracoes entre celulares.

Os dez registros da imagem enviada foram incluidos como dados iniciais.
