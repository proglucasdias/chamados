# Sistema de abertura de chamados

Esta pasta contém o projeto completo: portal do usuário, painel administrativo, servidor Node.js, redefinição de senha, exportação de relatórios, dependências, dados e cópias de segurança dos chamados.

## Iniciar localmente

Abra um terminal nesta pasta e execute:

```powershell
npm start
```

O servidor abre por padrão em `http://localhost:8080`.

Os dados ficam em `data`, os backups em `data/backups` e os relatórios exportados em `reports`.
